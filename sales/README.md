# Sales

Pipeline by stage. Pricing. Active deals worth tracking.

## Files

- `pipeline.md` — Active deals by stage. One paragraph each: name, stage, rough value range, next step, owner.
- `pricing.md` — What we charge, when, why. Recent pricing decisions log.

## Rules

- **Never put exact deal values in pipeline headlines.** Rough ranges OK ("€10–50k ARR").
- Move closed-won to `customers/<slug>.md` (full entity page).
- Move closed-lost to a timeline entry on `pipeline.md`, then prune from active list.
- This folder is sales-sensitive — `audience: internal` is mandatory.
