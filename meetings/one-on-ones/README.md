# One-on-ones

Manager 1:1s and founder–report check-ins.

- **Distill focus:** commitments made (both directions), recurring themes worth tracking, decisions affecting work. Brief — a 1:1 note is usually ≤150 words.
- **Propagate:** role/responsibility changes → `people/<slug>.md` and `management/accountability.md`; decisions → `decisions/`.
- **Hard rule:** **no compensation, performance-review, health, or personal-life content** — ever. If the conversation was primarily about those, write no note. The trust of 1:1s depends on this boundary; `audience: internal` is not protection enough.
