# Planning

Quarterly and annual planning sessions — the EOS quarterly pulse (review last quarter's rocks, set next quarter's) and the annual vision/plan reset, or whatever the company's planning rhythm is.

- **Distill focus:** goals set (with owner + measure), goals explicitly dropped, the reasoning behind force-ranked priorities, issues moved to/from the long-term list.
- **Propagate — this category exists to feed the canonical layer:** new quarter priorities → `strategy.md`; rocks → `operating-system/rocks.md` (previous quarter rolled below the `---` with final status); vision changes → `operating-system/vision.md`; each major commitment → `decisions/`. The planning note records the *session*; the artifacts hold the *plan*.
- **Don't:** let the note become the plan. If the plan only exists here, the propagation step was skipped.
