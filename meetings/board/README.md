# Board

Board meetings, investor updates, and formal investor calls.

- **Distill focus:** governance decisions, commitments made to/by the board, asks (intros, hiring help) with owners, concerns raised and the response.
- **Propagate:** strategic direction changes → `strategy.md` + `decisions/`; investor relationship facts → `people/<slug>.md` timelines; fundraising-round outcomes → `finance.md` (summary level only).
- **Hard rule:** no term-sheet details, valuation negotiations, cap-table movements, or comp discussions in the note — those live in the encrypted store `finance.md` points to. Summarize *around* them ("comp plan discussed; details offline").
