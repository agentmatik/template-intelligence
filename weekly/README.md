# Weekly

Friday founder/team brief. One file per ISO week.

## Naming

`YYYY-Www.md` — e.g. `2026-W17.md` (week 17 of 2026)

ISO week numbering beats month-based because weekly files sort in order forever.

## Content

See `templates/weekly.md`. Key sections:
- What shipped
- What we learned (the non-obvious thing)
- Customer signals
- Metrics (link, don't mirror)
- Blockers/risks
- Decisions this week
- Next week's focus
- Meetings

## How it's written

`/skill weekly-brief` pulls from `meetings/`, Linear (via MCP), `decisions/`, GitHub (via MCP). Drafts a brief. **You review and edit.** Never auto-merge a weekly — it's the alignment document; trust depends on human review.
