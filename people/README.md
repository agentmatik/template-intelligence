# People

Team, advisors, partners, investors. One file per person. Use `templates/person.md`.

## Strict rules

- **Internal-only by default.** Mark `audience: internal` in frontmatter.
- **No compensation, no performance reviews, no medical info, no personal details beyond work-relevant context.** Those live in your HRIS or encrypted store. Not here.
- Light-touch timeline — note role changes, departures, major contributions. Not every conversation.

When someone leaves: move to `people/alumni/` (or just `status: archived`). Don't delete — context preserves history.
